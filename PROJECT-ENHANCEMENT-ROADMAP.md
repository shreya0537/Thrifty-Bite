# Thrifty Bite — standout enhancement ideas

These are recommended next additions, separated from the features already present so the project does not claim functionality that has not been built or tested.

## 1. Smart Value Score (recommended next)
Score menu choices using price per portion, user-selected dietary preferences, rating data when available, and estimated serving count. Explain why an item is recommended instead of showing a mysterious score. Do not use fabricated competitor prices as live market data.

## 2. Dietary & allergen-aware menu filters
Let users filter vegetarian, vegan, Jain-friendly, egg-free, dairy-free, gluten-free and nut-aware options only when the menu record has verified tags. Show “confirm with restaurant” for unverified allergen details; never infer allergy safety from a dish name.

## 3. Dine Out visit planner
Allow users to compare estimated spend, travel distance, cuisine and preferred time, then save a shortlist. Show whether a booking is only a request or confirmed; only label it confirmed after the restaurant/provider confirms.

## 4. Transparent savings receipt
At checkout, show item subtotal, delivery/taxes/fees, discounts, and final payable amount separately. Compare only prices available in the stored dataset and label competitor values as sample/reference data where applicable.

## 5. Feedback-to-improvement loop
Use the existing website rating and feedback form to collect a rating, category and optional comment. An admin dashboard can later show average rating, common issues and trends, with access controls for private comments.

## Current requested changes in this build
- Removed the “Thrifty Bite Assistant” panel and its chatbot script from Group Orders.
- Removed the background-music script from the Menu page. The music feature remains available only on pages where its script is intentionally included (such as Home).
